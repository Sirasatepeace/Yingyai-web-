# Yingyai Academy — เว็บไซต์สถาบันสอนพิเศษออนไลน์

Node.js + Express + SQLite (ไม่ต้องติดตั้งฐานข้อมูลแยก)

## เริ่มใช้งาน

```bash
npm install
npm run create-admin -- <ชื่อผู้ใช้แอดมิน> <รหัสผ่าน>   # สร้างบัญชีผู้ดูแล (คุณ)
npm start                                                # เปิด http://localhost:3000
```

ใช้งานจริงให้ตั้งค่า `SESSION_SECRET` (สุ่มยาว ๆ), `NODE_ENV=production` และ `COOKIE_SECURE=1` เมื่อใช้ HTTPS

## ปรับให้เข้ากับแบรนด์
- **โลโก้**: `public/img/logo.png` (พื้นโปร่งใส) — เปลี่ยนไฟล์ได้ที่ `site.logo` ใน `src/config.js`
- **สีธีม**: แก้ 4 ค่าแรกใน `:root` ที่ `public/css/style.css` (`--brand`, `--brand-dark`, `--accent`, `--accent-dark`)
- **ชื่อสถาบัน / ช่องทางติดต่อ / บัญชีรับโอน**: `src/config.js`

## ฟีเจอร์
| ส่วน | รายละเอียด |
|---|---|
| คอร์ส | หน้ารวมคอร์ส ค้นหา/กรองวิชา ระดับชั้น ฟรี/มีค่าใช้จ่าย · ราคา 0 = ฟรี ลงทะเบียนได้ทันที · บทเรียนตั้งเป็น "ดูตัวอย่างฟรี" ได้ |
| ซื้อคอร์ส | นักเรียนโอนเงินแล้วแนบสลิป → แอดมินกดยืนยันที่ `/admin/payments` → เปิดสิทธิ์เรียน |
| สื่อการสอน | แอดมินอัปโหลดเทปเรียน (MP4/WEBM/MOV) และเอกสาร (PDF/Word/PPT/Excel/รูป/ZIP) ได้หลายไฟล์ต่อบท พร้อมแถบความคืบหน้า · ไฟล์ส่งผ่านเซิร์ฟเวอร์ที่ตรวจสิทธิ์ทุกครั้ง · วิดีโอเลื่อนดูได้ (HTTP Range) |
| สมัครสมาชิก | username, password, ชื่อ, นามสกุล, ชื่อเล่น, ชั้นเรียน, โรงเรียน |
| กันกรอกมั่ว | ชื่อต้องเป็นไทยล้วนหรืออังกฤษล้วน · ตรวจโครงสร้างการสะกดไทย (ตำแหน่งสระ/วรรณยุกต์/การันต์) · จับการไล่แป้นคีย์บอร์ด (ฟหกด, asdf) ตัวอักษรซ้ำ รูปแบบซ้ำ · คำต้องห้าม/คำหยาบ · ห้ามใส่คำนำหน้า · ชื่อกับนามสกุลต้องภาษาเดียวกันและไม่ซ้ำกัน · กันสมัครซ้ำ (ชื่อ-สกุล-โรงเรียนเดียวกัน) · honeypot + จับเวลากรอกกันบอท · จำกัดการสมัครต่อ IP |
| โรงเรียน | ฐานข้อมูลโรงเรียนทั่วประเทศ ~34,800 แห่ง พร้อมช่องค้นหาอัตโนมัติ · **ถ้าไม่ตรงกับรายชื่อ → บัญชีรออนุมัติ** ที่ `/admin/users` (แอดมินเลือกโรงเรียนที่ชื่อใกล้เคียง, เพิ่มเป็นโรงเรียนใหม่ หรือปฏิเสธ) · ถ้าชั้นเรียนไม่ตรงกับระดับที่โรงเรียนเปิดสอน (เช่น ม.5 แต่โรงเรียนเปิดถึงแค่ ป.6) ก็เข้าคิวรออนุมัติเช่นกัน |
| ความปลอดภัย | รหัสผ่าน bcrypt · CSRF token · ล็อกการเข้าสู่ระบบหลังผิด 5 ครั้ง · session เก็บใน SQLite |

รายชื่อโรงเรียน (`data/schools-th.json`) รวบรวมจาก Wikipedia ผ่านโปรเจกต์ [thrxpt/thai-school-data](https://github.com/thrxpt/thai-school-data) — เพิ่มเติมได้ที่ `/admin/schools` (ทีละแห่งหรือนำเข้า CSV)

## ข้อมูลและไฟล์
ทุกอย่างอยู่ใน `storage/` (ฐานข้อมูล `app.db` + `uploads/`) — สำรองโฟลเดอร์นี้โฟลเดอร์เดียวพอ · เปลี่ยนที่เก็บได้ด้วย `DATA_DIR` · ขนาดอัปโหลดสูงสุด `MAX_UPLOAD_MB` (ค่าเริ่มต้น 4096)
